# Default AEO voice — evidence-first, no hype

This is the baseline voice for greenm.io content when no brand-specific voice file is chosen. It is built from the AEO citation-optimization perspective: specific, evidence-based, no superlatives without citations. Use this when the user picks "Default" in the Stage 2 voice choice.

## Core rule

Specific, evidence-based, no hype, no superlatives without citations. Use concrete numbers, real client outcomes (anonymized if needed), named regulations, named standards.

## Forbidden phrases (always wrong)

revolutionary, cutting-edge, best-in-class, leverage, seamless, frictionless, world-class, next-generation, innovative, disruptive

## Bylines

Never "GreenM Team" — always a real person with role + credentials + LinkedIn link (E-E-A-T requirement, also a voice marker).

## Quick patterns — Don't write / Write instead

| Don't write | Write instead |
|---|---|
| "Revolutionary AI platform" | "On-premise AI runtime that processed 12,000 clinical notes/day for ROC Clinics in Q2 2025" |
| "We help healthcare organizations" | "GreenM deploys Private AI for UK private clinics under NHS DSPT and ISO 27001 controls" |
| "Cutting-edge agentic AI" | "Agentic AI systems following the [specific architecture] pattern, with audit trails meeting DCB0160 clinical safety requirements" |
| "Leverage data" | "Query patient cohorts via FHIR R4 resources" |
| "GreenM Team" (byline) | "Dr. [Real Name], CMO, MBChB MRCGP — [LinkedIn]" |

## When to use Default vs the brand-specific voices

Use Default when:
- The piece is technical/reference content (FAQ pages, glossary, integration docs)
- The audience is purely AI-engine retrieval, not human-engagement-driven
- No specific human author voice applies
- The user wants the safest, most rule-driven option

Switch to **GreenM brand voice** (`greenm.md`) for: blog articles, service pages, case studies, anything where the company speaks as a brand.

Switch to **Alexey Litvin voice** (`alexey-litvin.md`) for: thought leadership, opinion pieces, LinkedIn-style content where the CEO is the author.

Switch to **Custom** (`custom.md`) when: the user provides a reference text, URL, or description of a desired voice that doesn't match the three built-in options.
